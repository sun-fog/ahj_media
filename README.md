# AHJ Media — Timeline с текстом, аудио и видео


![CI](https://github.com/sun-fog/ahj_media/actions/workflows/deploy.yml/badge.svg)

[Запустить приложение](https://sun-fog.github.io/ahj_media/ "Откроется страница приложения на GitHub Pages")


Домашнее задание к занятию "10. Geolocation, Notification, Media".
Одностраничное приложение-лента: пользователь добавляет записи с текстом,
аудио или видео. Каждая запись автоматически получает координаты из
Geolocation API, а при их недоступности координаты можно указать вручную.

## Возможности

- **Текстовая запись** — ввод текста в нижнее поле и Enter. Перед добавлением
  запрашиваются координаты через Geolocation API. Если получить их не удалось,
  открывается модальное окно с ручным вводом в формате «широта, долгота»
  (поддерживаются необязательные квадратные скобки).
- **Аудио** — кнопка 🎤 запускает запись с микрофона (MediaRecorder).
  Повторный клик останавливает запись и добавляет её в ленту.
- **Видео** — кнопка 📹 открывает модальное окно с живым предпросмотром
  с камеры; «Записать» начинает запись, «Остановить» завершает её и
  добавляет пост в ленту.
- **Cancel** — во время записи аудио и на любом этапе записи видео можно
  отменить: запись отбрасывается и в ленту не попадает.
- Невалидный формат координат подсвечивает поле и показывает сообщение
  об ошибке; ошибки доступа к микрофону/камере выводятся отдельной плашкой.
- Записи хранятся в памяти как base64 data URL; рендер безопасен
  (экранирование содержимого).

## Стек

- Ванильный JavaScript (ES-модули), Webpack, Babel
- Geolocation API, MediaRecorder API, getUserMedia
- Jest (тесты), ESLint (airbnb + prettier), HtmlWebpackPlugin
